Zona 1: La máquina de enlaces

E01 · El Conector de Energía

Revisa las conexiones entre los conjuntos de entrada y salida. Decide si la relación es una función.

Entradas: A = {1, 2, 3}

Salidas: B = {4, 5}

Conexiones: R = {(1, 4), (2, 4), (3, 5)}

Opciones: Es función / No es función.

Ver respuesta

Es una función.

Cada entrada tiene una sola salida. Que 1 y 2 lleguen a la misma salida, 4, sí está permitido.

E02 · El Cortocircuito de Unicidad

Elige una conexión que quieras quitar. Así, cada entrada quedará con una sola salida y la relación será una función.

Entradas: A = {1, 2, 3}

Salidas: B = {4, 5}

Conexiones: R = {(1, 4), (1, 5), (2, 4), (3, 5)}

Puedes quitar (1, 4) o (1, 5).

Ver respuesta

Hay dos respuestas posibles:

  • Quitar (1, 5): R = {(1, 4), (2, 4), (3, 5)}.
  • Quitar (1, 4): R = {(1, 5), (2, 4), (3, 5)}.

La entrada 1 tenía dos salidas. Las entradas 2 y 3 ya estaban bien conectadas.

E03 · Restauración de Existencia

Conecta la entrada que no tiene salida. Elige cualquiera de las dos salidas.

Entradas: A = {1, 2, 3}

Salidas: B = {4, 5}

Conexiones actuales: R = {(1, 4), (3, 5)}

La entrada 2 no tiene conexión. Conéctala a 4 o a 5.

Ver respuesta

Las dos opciones son:

  • Conectar (2, 4): R = {(1, 4), (2, 4), (3, 5)}.
  • Conectar (2, 5): R = {(1, 4), (2, 5), (3, 5)}.

Cada entrada debe tener una salida. La entrada 2 debe tener solo una conexión.

Zona 2: El escáner de proyección

E04 · Escáner de Señal Lineal

Encuentra el dominio y el rango de la función. El dominio son los valores que puede tener x. El rango son los valores que puede tomar la función.

Función: f(x) = 2x − 1

Escribe el dominio y el rango con intervalos.

Ver respuesta

Dominio: (−∞, +∞) = ℝ.

Rango: (−∞, +∞) = ℝ.

La recta continúa sin límite hacia ambos lados y también hacia arriba y abajo.

E05 · Límite de Altura Cuadrático

Encuentra el dominio y el rango. Indica la altura más baja que alcanza la parábola.

Función: f(x) = (x − 2)² + 1

La parábola abre hacia arriba y su vértice está en (2, 1).

Ver respuesta

Dominio: (−∞, +∞) = ℝ.

Rango: [1, +∞).

La altura mínima es 1 y sí se alcanza en el punto (2, 1).

E06 · El Umbral Logarítmico

Encuentra el dominio de la función. También indica el valor de x al que se acerca la curva sin tocarlo.

Función: f(x) = log₂(x − 3)

El valor dentro del logaritmo debe ser mayor que cero.

Ver respuesta

Dominio: (3, +∞), es decir, x > 3.

Asíntota vertical: x = 3.

El valor 3 no se incluye porque log₂(0) no está definido en los números reales.

Zona 3: Sintonizador de trayectorias

E07 · Sintonizador de Pendiente

Ajusta los valores de m y b para que la recta pase por los dos puntos.

Función: f(x) = mx + b

Puntos: (0, 4) y (2, 0).

Ver respuesta

m = −2 y b = 4.

La función es f(x) = −2x + 4.

E08 · Foco del Vértice

Escribe la función en la forma (x − h)² + k. Luego indica el vértice y el eje de simetría.

Función: f(x) = x² − 6x + 11

Ver respuesta

Forma: f(x) = (x − 3)² + 2.

Vértice: (3, 2).

Eje de simetría: x = 3.

E09 · Eco de Preimágenes

Encuentra todos los valores de entrada x que dan como resultado 8.

Función: f(x) = x² − 1

Valor de salida: y = 8

Ver respuesta

Entradas: x = −3 y x = 3.

Conjunto: S = {−3, 3}.

Ambas entradas funcionan: (−3)² − 1 = 8 y 3² − 1 = 8.

Zona 4: Espejo de las inversas

E10 · Frecuencia Exponencial

Analiza la función. Indica su dominio, su rango y la línea horizontal a la que se acerca la curva.

Función: f(x) = 2ˣ

La curva pasa por (0, 1) y crece.

Ver respuesta

Dominio: (−∞, +∞) = ℝ.

Rango: (0, +∞).

Asíntota horizontal: y = 0.

La función siempre es mayor que cero. Se acerca a cero, pero no lo alcanza.

E11 · El Reflejo de la Inversa

Refleja la función f(x) = 2ˣ sobre la línea y = x. Escribe el dominio y el rango de la función inversa.

Función inversa: g(x) = log₂(x)

Al reflejar, los puntos (0, 1) y (1, 2) pasan a (1, 0) y (2, 1).

Ver respuesta

Dominio de g: (0, +∞).

Rango de g: (−∞, +∞) = ℝ.

Asíntota vertical: x = 0.

E12 · Conversión de Poder

Convierte la potencia en una expresión con logaritmo. Luego encuentra el valor de x.

Regla: 3ˣ = 81

Equivalencia: aʸ = x significa lo mismo que y = logₐ(x).

Ver respuesta

log₃(81) = x.

Como 3⁴ = 81, entonces x = 4.

E13 · Filtro del Satélite

Función: f(x) = log₅(x − 4)

Ver respuesta

E14 · Verificador de Imposibles

Encuentra el conjunto de entradas que da como resultado −2 en cada módulo.

  1. Módulo exponencial: 2ˣ = −2. Encuentra S₁.
  2. Módulo lineal: 3x + 1 = −2. Encuentra S₂.
Ver respuesta

Módulo exponencial: S₁ = ∅. No hay una potencia de 2 que dé un número negativo.

Módulo lineal: S₂ = {−1}, porque 3(−1) + 1 = −2.

E15 · Núcleo Integrado a Trozos

Usa la regla que corresponde en cada caso. Encuentra f(−2), f(0) y el dominio total.

Función por tramos:

f(x) = x + 2, si x < 0
f(x) = (x − 3)² + 2, si x ≥ 0
Ver respuesta

f(−2) = 0, porque −2 < 0.

f(0) = 11, porque para x = 0 se usa la regla (x − 3)² + 2.

Dominio total: (−∞, +∞) = ℝ.
