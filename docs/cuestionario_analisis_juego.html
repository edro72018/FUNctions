Entendamos FUNctions: del juego web a un plan claro

¡Bienvenido! Aquí aprenderás qué es un juego web, cómo se juega y qué hacen las herramientas elegidas para FUNctions. También descubrirás las reglas aprobadas, cómo guardar el avance y cómo comprobar que el juego funciona antes de compartirlo. No necesitas saber desarrollar videojuegos.

Esto es una práctica, no una aprobación del proyecto. Cada pregunta tiene una sola respuesta correcta. Las reglas del GDD v0.1 están aprobadas; esto no significa que ya se hayan implementado o probado.

  1. Lee la breve introducción de cada sección y elige una opción por pregunta.
  2. Recibirás una explicación al responder. Puedes cambiar tu respuesta para aprender.
  3. Abre «Ver respuesta y explicación de cada opción» si quieres repasar todas las alternativas.
  4. Descarga tus respuestas antes de cerrar o recargar: esta página no las guarda automáticamente.

No se piden nombres ni se envían respuestas a un servidor. El botón de descarga crea respuestas_analisis_juego.md, un archivo de texto con títulos y listas que puedes abrir con cualquier editor.

Qué te llevas de este cuestionario

  • Primero, la experiencia: objetivo, acciones, ayudas y condiciones para avanzar deben quedar claras.
  • Cada herramienta tiene su trabajo: mostrar una gráfica no es lo mismo que comprobar una respuesta matemática.
  • Guardar no es sincronizar: el avance local no se traslada por sí solo a otro dispositivo.
  • Terminar exige comprobar: hacen falta pruebas concretas, acceso público y la documentación acordada.
